# Code of conduct

Neolinter follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
summarized here.

## Our standard

Be respectful and constructive. Welcome newcomers, accept feedback graciously, and focus on what is best for the
project. Harassment, discrimination, personal attacks, trolling, and publishing someone else's private
information are not acceptable, in issues, pull requests, discussions or any other project space.

## Enforcement

Maintainers may edit or remove contributions, and temporarily or permanently ban contributors, for behavior
that breaks this code. Report a problem privately through
[GitHub's private reporting](https://github.com/neolinter/neolinter/security/advisories/new) (mention that it
is a conduct report); reports are handled confidentially.
